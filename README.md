Lantern Harbor — an original spot-the-difference game: two near-identical pictures side by side, 7 differences hidden in each of 3 hand-drawn scenes (Dusk Harbor, Mossy Garden, Night Market), a 3:00 timer, hints, score and a win screen. Built by an AI agent for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a difference on either picture to circle it. `H` hint, `R` restart level, `M` sound.
